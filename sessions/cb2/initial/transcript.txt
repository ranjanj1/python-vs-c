Otherwise the token is emitted; then i    f count == max_new it ends with `max`. If the next forward position would be seq_len, it ends with `context`.  36 - **Prompt length:** a prompt longer than seq_len gives `DONE 0 context`. A prompt of exactly seq_len still emit    s one token, as the reference does. 37 - **`GENERATE 0 …`** answers `DONE 0 max` without running the model. 38 - **PIECE** prints `HEX ` followed by the bytes of the piece as a C string. An empty piece (for example `PIECE 1     29871`) gives `HEX ` with nothing after it. `<0x00>` also comes out empty, because the reference treats the pie     ce as a C string. 39 - **Malformed commands,** out-of-range ids, or FIXED/LOGITS with more than seq_len ids get an `ERR …` line. Thes    e cases are not part of the contract. 40 - **KV cache between commands:** it is not re-zeroed. Every command writes positions 0..n-1 before reading them     and never reads past the current position, so no state carries over from one command to the next.  41  42 ## Results (this machine) 43  44 - Load to READY takes about 0.08–0.12 s. 45 - Decode runs at about 79 tok/s.
